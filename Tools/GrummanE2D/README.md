# Grumman E-2D visual asset

The model generated by `build_model.py` is original, lightweight geometry made
for this project. Its two turboprops, high wing, and elevated radar rotodome
make the E-2D Hawkeye recognizable in the Construction Menu and on the map.

This is a stylized in-game representation, not a sourced or factory-accurate
model. It uses no third-party mesh or textures. The generator writes the OBJ and
MTL under `Assets/Art/Unidades/GrummanE2D/`.
